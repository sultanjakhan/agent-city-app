    Разделы и расположение
    Preview выбора
    Preview показывает только счётчики и состояние файлов. Названия задач, заметки и ответы моделей не выводятся.
    Применённые сводки
    Приватный Git — отдельное действие
    Создание папок не создаёт Git-репозиторий и не загружает данные в сеть. Подключи локальную папку приватного репозитория, который ты создал отдельно, или создай приватный репозиторий вручную после проверки файлов.
    Не добавляй в Git ключи, сессии, облачные профили и локальные пути компьютера. Переносимая конфигурация содержит только относительные папки и настройки отображения.
    В облако передаются только зашифрованные отчёты работы. Правила, навыки, настройки и ключи моделей пока остаются на устройстве.
    Не сохраняй в правилах пароли, ключи и личное содержимое задач.

    Изменения перед сохранением
    История версий
    

    Настройки провайдера
    Способ доступа — ваш выбор, не подтверждение авторизации. Подписка не даёт бесплатный API.
    Политика каталога меняет отображение. «Все модели» включает платные и модели с неизвестной ценой.
    Метаданные каталога загружаются отдельно. Смена настроек не обновляет каталог, не подключает аккаунт и не вызывает модели.
    Источник и дата относятся к получению данных; опубликованный список не подтверждает доступ аккаунта.
    

    

    Добавить провайдера
    Сайт и API — разные адреса. Для известного сайта используется встроенный адаптер. Остальные ссылки сохраняются без импорта моделей и ввода токена.
    В моделях показываем только подтверждённую нулевую цену. Бесплатная квота и неизвестная цена не равны нулевому тарифу.
    Ключ сохраняется только для известного API-адаптера. Для неизвестного сайта оставь поле пустым. Добавление не обновляет каталог и не вызывает модель.
    

    Удалить провайдера
    Провайдер исчезнет из списка и обновления каталогов. Сохранённые ключи, отчёты и снимки не удаляются. Известный провайдер восстанавливается добавлением его сайта.
